# GFTV PolicySpot

The official policy documentation platform for **Global Furry Television (GFTV)** — available on the web and as bots on Discord and Telegram.

## Platforms

| Platform | Description | Docs |
| --- | --- | --- |
| 🌐 Web | The main SPA — browse, search, and manage policy documents | [main-site/](main-site/README.md) |
| 💬 Discord | Slash-command bot for browsing, searching, and tracking policy content in Discord | [discord-bot/](discord-bot/README.md) |
| ✈️ Telegram | Bot that delivers the full PolicySpot experience via Telegram DMs | [telegram-bot/](telegram-bot/README.md) |

All three platforms share the same underlying Supabase database and view-count analytics, so content edited on the web is instantly reflected in both bots.
